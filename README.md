# Kanvtech-Business-operation-Platform-

**KANVTECH Business Operations Platform** is an enterprise SaaS platform built for multi-regional Facilities & Technical Field Services management, unifying executive decision intelligence and human capital operations.

---

## 🌟 Key Functional Architecture

- **CEO Executive Operating Center**:
  - Financial & Revenue Trajectory Analytics (`Today`, `7 Days`, `30 Days`, `Quarter`)
  - Real-Time SLA Health & Critical Penalties Monitoring
  - Operations & Work Order Distribution across 5 Regional Service Hubs
  - Customer Accounts & Service Contracts Intelligence
  - Field Assets & Technical Spare Parts Inventory
  - AI-Powered Decision Support & Capacity Simulation Engine ("Ask Company")
- **People Operations (HR Command Center)**:
  - Canonical Headcount & 5-Hub Regional Capacity Analysis
  - Real-Time Attendance Pulse & Shift Absence Tracking
  - End-to-End Recruitment Pipeline (Sourced $\to$ Screened $\to$ Interviewed $\to$ Offered)
  - Skills Matrix & Certification Expiry Compliance Auditing
  - Workforce Planning & Statutory Payroll Overview
- **Enterprise Design & Navigation**:
  - Collapsible desktop navigation rail expanding workspace to full screen
  - Responsive slide-out mobile drawer with touch backdrop and accessible focus management
  - Cohesive multi-dimensional filtering across Period, Region, and Business Unit
  - Global Command Palette (`⌘K`), quick-search, and context-sensitive drill-down drawers

---

## 🛠️ Technology Stack

- **Framework**: [React 18](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Bundler / Tooling**: [Vite](https://vitejs.dev/)
- **Data Visualizations**: [Chart.js](https://www.chartjs.org/) + [react-chartjs-2](https://react-chartjs-2.js.org/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Styling**: Vanilla CSS Design System with strict enterprise semantic design tokens

## 🚀 Getting Started Locally

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Development Server
```bash
npm run dev
```

### 3. Build for Production
```bash
npm run build
```

### 4. Preview Production Build
```bash
npm run preview
```
